# RedTain

An **Open Source & Open World - Public Domain** video game made to give players an entirely new experience with hyper-realistic world and a never ending community built story, The game aims to leave all the decisions on the players to decide what they wants to do. The game itself is will never end in any ways. The only goal of the player is to keep up with the changing world, Every single update adds something new , As the technology keeps getting more and more advanced the game also starts getting more and more futuristic. And this all is possible due to the community contributions.

The game itself is licensed under the CC0 License (Check out the LICENSE Files for more information) how ever, The engine used to make the game (**Godot**) and it's plugins / addons comes with their own licenses. Please be sure to respect them. Their licenses are kept in their respective addons directory.

## How to install ?

As of now the game is in it's early stage of development. There is pretty much nothing to play. how ever the source code is still publically available for everyone to see , change and make their own changes.

## What to do if you encounter an issue such as a bug ?
If you encounter a bug or any issue then the first thing you should do is to update the game. The project follows the rolling release model instead of traditional update based fixes  so there is a very good chance that your issue might be there due to a problematic commit and the community already fixed by making another commit. So the first thing you should do is to update your game. If updating does not fixes it then you can open an issue in the issues tab of the repository and describe the problem. If possible then also include technical details such as the operating system , build name etc.
