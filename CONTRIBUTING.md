# Want to contribute ?
All the types of contributions are accepted regardless of your skill level. Just make sure to follow these guidelines

## Guidelines
The guidelines are presented in 2 parts, Core and General. The Core guidelines can be reframed to be more gramatically correct but their meaning can not be changed by any means unless there is a legal requirement how ever the general guidelines can be modified by the community at any time but the modification shall be passed through multiple top level maintainers otherwise the changes won't be passed. Also remember that these guidelines really depends a lot on the maintainer / repository. They can change all of them , Including the core guidelines. These guidelines that you are seeing right now are the official guidelines , How ever maintainers can still rewrite the core guidelines if needed.

### Core Guidelines
 - **Submitting Assets**: *If you are submitting any sort of assets then pleae make sure that the assets are either created by you or are under the **CC0-v1** License and you have the permissions to use and distribute them. if the assets are made by you or you owns them then be aware that by submitting your assets to this project in any way will distribute them under the **CC0-v1** license (Public Domain) so be super careful with the asset submittion as you might actually loose the rights to copyright anyone once they are accepted. if you mistakenly submitted your assets without knowing about the CC0 License then you can try to make an issue or contact other developers to get your assets removed from the projects, Although once submitted this is not guaranteed as the project might be already distributed till then.*
 
 - **Submitting code**: If you are submtting your own code or modifying some existing parts of code from the project. Then make sure to comment every major part so that if anyone else reads your code then they can get it without having a lot of confusion. This is a request not something mandatory 😅. But we will highly appreciate the comments in code. Also remember that any changes you submit will be published under the **CC0-v1** License so be careful because you won't be able to claim copyrights on code at all (Plugins are exceptions)
 
 - **Using a plugin/addon in your submittion**: If you use a plugin / addon in your contribution then please make sure that the plugin/addon is completely open source or made by you. You can use a standard open source license with your own plugins but the license must be a standard open source license like MIT, Apache V2 etc. And if you use someone else's plugin then make sure that the license is a standard open source license and you are not violating it's terms & conditions. 
 
 - **No proprietiary Usage**: Usage of a proprietiary plugin/addon/asset or anything , Is strictly not allowed! You must use open sourced things (Who have a standard open source license!) in order to make a contribution to the project. 
 
 - **No custom license is allowed**:  If you are submitting something that you owns like plugin/addon then make sure that they are covered by a standard open source license. No custom license will be accepted, Not even those custom licenses which "pretends" to be open source. If you want to contribute then use a standard open source license like MIT or Apache V2.
 
 - **Submitting audio / voice overs / 3d models / animations**: if you are submitting your own **audio**, **voice overs**, **3d models**, **animations** then please! Be aware that they all will be licensed under the CC0-v1 , If you don't want to loose the copyright protection then do not contribute with any of them 😅. How ever if you are submitting someone else's **audio**, **voice overs**, **3d models**, **animations** then make sure that they are already under the CC0-v1 license. Or the contribution will not be accepted.
 
 - **Using real logos/trademark**: Using someone else's assets / logos / trademarks which exists in real life is not allowed! And will not be accepted as it can be considered illegal in many nations.
 
 - **Submitting the artwork**: If you are submitting your art work then be aware that they will be covered under the **CC0-v1 License** how ever if you are submitting someone else's artwork then make sure that it's already under the **CC0-v1** License.
 
 > Note: These guidelines can not changed by the community unless their is a legal requirement. Rephrasing them is allowed but changing the meaning is strictly not allowed. New points can be added to these guidelines and old ones can be replaced (Not deleted) without changing the meaning or destroying some information.
 
 - **Guideline Acknowledgement**: While making a pull request to submit something make sure to include "I have read all the submittion guidelines and i guarantee that my contribution does not violate any of them", This is a must. You can add this note in your own terms , No need to copy paste the exact text but you have to give an acknowledgement to the community that you havve actually read the guidelines and you are respectfully agreeing with them and not violating them. Feel free to add the acknowledgement in the pull request's comment box , Your request's description. Just add it! That's what matters the most, And add it somewhere where everyone can clearly see that.
 
 - **No unauthorized network access**: Your submittion should not include any of the ways to collect the user information or anything from the player's machines. Anything like this will not be accepted as the contribution and the game itself should be completely offline. If the internet access is required to add online multiplayer then the code should always ask the player for their concent and should tell them the exact source where the data will go. Player can also deny that if they want and the code should respect that.
 
### General Guidelines
 - **Enough Spacing In The Code**: If you are writing the code to contribute then try to add enough spacing as that really helps other developers to read your code more comfortably without having to resize their eye balls like crazy.
 
 - **Submitting new houses**: If you are submitting new houses then please make sure that the house is modeled in the godot engine and also have interior because the player must be able to go inside the house for any reasons.
 
 > Note: The guidelines ends here. But the General Guidelines can be actually updated in future if needed.

## What can you really submit ?
You can submit pretty much anything including:
 - 3d models 
 - Audio
 - Voice overs
 - Characters
 - Ideas for the new mission
 - New map design
 - Animations
 - Polishing existing things!
 
Basically anything! Every contribution is accepted until they follows all the guidelines.

## What can i do as a player ?
Well you can do a lot of things! Maybe submit new map's sketch , New character's sketch etc. Just give it a try! And let the community bring your idea to the reality!
